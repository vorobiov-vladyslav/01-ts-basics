# 01-ts-basics

Homework 1: TypeScript basics, using Vite and Axios.

## Run locally

```sh
npm install
npm run dev
```

Open the local URL printed by Vite and open the browser developer console to see the exercise results.

## Checks

```sh
npm run typecheck
npm run build
npm run format:check
```

Use `npm run format` to format the project with Prettier.

## Exercises

Each task lives in `src/task-1.ts` through `src/task-8.ts`, and `src/main.ts` runs all eight. Task 8 requests posts from JSONPlaceholder. Task 6 assumes a nonempty input array.

The task files use representative examples because the original starter snippets were unavailable. Original values, calls, messages, and delays still need verification before submission.
